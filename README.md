# Event-Management-System
A lightweight web-based Event Management System that enables users to seamlessly explore, register, and manage events, while providing administrators with tools to organize and monitor event activities efficiently.

# Overview
In traditional event setups, managing registrations, tracking participants, and updating event details can be time-consuming and disorganized.
This project addresses those challenges by offering a centralized platform where:

Users can browse and register for events بسهولة
Event organizers can create and manage events in one place
Participants can view event details, schedules, and updates
The system ensures smooth coordination between users and administrators

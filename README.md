# Event-Management-System
A lightweight web-based Event Management System that enables users to seamlessly explore, register, and manage events, while providing administrators with tools to organize and monitor event activities efficiently.

# Overview
In traditional college event setups, managing registrations, tracking participants, and updating event details can be time-consuming and disorganized.
This project addresses those challenges by offering a centralized platform where:

Users can browse and register for events بسهولة
Event organizers can create and manage events in one place
Participants can view event details, schedules, updates and buy tickets.
The system ensures smooth coordination between users and administrators

# Core Concepts demonstrated
1) Queue Management (FIFO)
2) Client-Server Architecture
3) Asynchronous Requests (AJAX / Fetch API)
4) Real-Time Updates using Polling
5) Basic State Management (Pending → Ready)

# Why this project
This project focuses on solving a real-world problem among students using simple but effective system design.
Instead of overengineering, it demonstrates how basic technologies can be used to build a practical and efficient solution.
